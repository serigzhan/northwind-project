# Northwind Database setup

1. Open SQL Server Object Explorer
2. Create new database with name - 'NorthwindDB'
3. Click menu File -> Open -> File
4. Select 'instnwnd.sql' from root folder
5. Connect to Server
6. Select db from master -> NorthwindDB
7. Click 'Execute'

## Get connection string (if needed)
1. Right click to 'NorthwindDB' -> Properties
2. Find 'Connection String' 
3. Copy to appsettings.json
